# Документ об API для автоматизации приёма сообщения о пожаре (ЧС)

**Версия:** 1.0  
**Дата:** 11 сентября 2026  
**Заказчик:** начальник пожарно-спасательного гарнизона (ПСГ)  
**Исполнитель:** команда аналитиков и разработчиков

---

## Назначение документа

Этот документ описывает API, которое обеспечивает работу автоматизированного рабочего места (АРМ) диспетчера пожарной части. API связывает три компонента:

1. **АРМ диспетчера** (клиентское приложение, с которым работает диспетчер).
2. **АИС пожарной охраны** (источник мастер-данных: расчёты, районы выезда, техника, статусы, документы предварительного планирования).
3. **Мессенджер MAX** (канал автоматической рассылки информации о выезде караула).

Принцип: **данные берутся из АИС, результат возвращается в АИС, уведомления уходят в MAX**. Никаких параллельных справочников и вторых журналов вызовов.

---

## Аутентификация и авторизация

### Тип аутентификации

- **Внутренние сервисы (АРМ ↔ API Gateway ↔ АИС):** JWT-токены, выдаваемые по логину/паролю пользователя или по сертификату.
- **MAX Bot API:** Bearer-токен бота, выданный платформой MAX.

### Роли пользователей

| Роль | Описание |
|------|----------|
| `Диспетчер пожарной части` | Может создавать вызовы, просматривать справочники, инициировать рассылку в MAX. |
| `Командир караула/части` | Может просматривать вызовы, подтверждать выезд, менять статусы. |
| `Администратор системы` | Управление пользователями, настройка интеграций, аудит. |

### Заголовки запросов

```http
Authorization: Bearer <jwt_token>
Content-Type: application/json
```

## Endpoints API

### Справочники (чтение из АИС)

#### `GET /api/v1/stations`

**Описание:** Получить список пожарных частей (караулов).

**Ответ:**
```json
[
  {
    "id": "station-001",
    "name": "Пожарная часть №1",
    "address": "ул. Ленина, 1",
    "district_id": "district-01",
    "status": "active"
  }
]
```

---

#### `GET /api/v1/crews`

**Описание:** Получить список расчётов (караулов) с текущими статусами.

**Параметры:**
- `station_id` (optional) — фильтр по части.
- `status` (optional) — фильтр по статусу (`free`, `busy`, `maintenance`).

**Ответ:**
```json
[
  {
    "id": "crew-101",
    "station_id": "station-001",
    "name": "Караул №1",
    "status": "free",
    "vehicle_type": "AC-40",
    "crew_size": 5,
    "last_updated": "2026-09-12T11:00:00Z"
  }
]
```

---

#### `GET /api/v1/districts`

**Описание:** Получить районы выезда.

**Ответ:**
```json
[
  {
    "id": "district-01",
    "name": "Район выезда №1",
    "stations": ["station-001", "station-002"],
    "polygon": { }
  }
]
```

---

#### `GET /api/v1/vehicles`

**Описание:** Получить справочник техники.

**Ответ:**
```json
[
  {
    "id": "vehicle-201",
    "type": "AC-40",
    "name": "Автоцистерна 40",
    "capacity": 4000,
    "crew_capacity": 5
  }
]
```

---

### Документы предварительного планирования

#### `GET /api/v1/planning-documents?address={address}`

**Описание:** Проверить наличие документа предварительного планирования (ДПП) по адресу объекта пожара.

**Параметры:**
- `address` — адрес объекта (строка).

**Ответ:**
```json
{
  "found": true,
  "document_id": "dpp-5001",
  "object_name": "Торговый центр «Плаза»",
  "address": "ул. Мира, 45",
  "hazard_class": "A",
  "evacuation_routes": [ ],
  "fire_load": "высокая",
  "special_notes": "Имеется аммиачная холодильная установка"
}
```

Если документ не найден:
```json
{
  "found": false
}
```

### Вызовы (создание и управление)

#### `POST /api/v1/calls`

**Описание:** Создать новый вызов (сообщение о пожаре/ЧС).

**Тело запроса:**
```json
{
  "caller_name": "Иванов И.И.",
  "caller_phone": "+7-900-123-45-67",
  "address": "ул. Мира, 45",
  "object_name": "Торговый центр «Плаза»",
  "incident_type": "fire",
  "description": "Задымление на 2 этаже, торговый зал",
  "received_at": "2026-09-12T11:15:00Z",
  "district_id": "district-01"
}
```

**Ответ:**
```json
{
  "id": "call-9001",
  "status": "new",
  "created_at": "2026-09-12T11:15:01Z",
  "assigned_crews": [],
  "ais_call_id": "AIS-2026-09-12-0042"
}
```

---

#### `GET /api/v1/calls/{call_id}`

**Описание:** Получить информацию о вызове.

**Ответ:**
```json
{
  "id": "call-9001",
  "caller_name": "Иванов И.И.",
  "caller_phone": "+7-900-123-45-67",
  "address": "ул. Мира, 45",
  "object_name": "Торговый центр «Плаза»",
  "incident_type": "fire",
  "description": "Задымление на 2 этаже, торговый зал",
  "received_at": "2026-09-12T11:15:00Z",
  "status": "dispatched",
  "assigned_crews": ["crew-101", "crew-102"],
  "ais_call_id": "AIS-2026-09-12-0042",
  "planning_document": {
    "found": true,
    "document_id": "dpp-5001"
  }
}
```

---

#### `POST /api/v1/calls/{call_id}/assign`

**Описание:** Назначить расчёт(ы) на вызов.

**Тело запроса:**
```json
{
  "crew_ids": ["crew-101", "crew-102"],
  "assigned_by": "dispatcher-001",
  "assigned_at": "2026-09-12T11:16:00Z"
}
```

**Ответ:**
```json
{
  "call_id": "call-9001",
  "assigned_crews": ["crew-101", "crew-102"],
  "status": "dispatched"
}
```

---

#### `POST /api/v1/calls/{call_id}/status`

**Описание:** Обновить статус вызова (например, «выехали», «на месте», «ликвидирован»).

**Тело запроса:**
```json
{
  "status": "arrived",
  "updated_by": "commander-005",
  "updated_at": "2026-09-12T11:25:00Z",
  "comment": "Прибыли на место, приступили к разведке"
}
```

**Ответ:**
```json
{
  "call_id": "call-9001",
  "status": "arrived",
  "updated_at": "2026-09-12T11:25:00Z"
}
```

### Путёвка (генерация и печать)

#### `POST /api/v1/calls/{call_id}/waybill`

**Описание:** Сформировать путёвку для выезжающих отделений.

**Тело запроса:**
```json
{
  "crew_ids": ["crew-101", "crew-102"],
  "copies_count": 3
}
```

**Ответ:**
```json
{
  "waybill_id": "waybill-7001",
  "call_id": "call-9001",
  "pdf_url": "[https://api.example.com/files/waybill-7001.pdf](https://api.example.com/files/waybill-7001.pdf)",
  "copies": 3,
  "created_at": "2026-09-12T11:16:05Z"
}
```

**Примечание:** PDF генерируется на основе шаблона, данные берутся из вызова и справочников АИС.

### Карта местности

#### `GET /api/v1/map/district?address={address}`

**Описание:** Получить GeoJSON района выезда для адреса объекта пожара.

**Параметры:**
- `address` — адрес объекта.

**Ответ:**
```json
{
  "address": "ул. Мира, 45",
  "district_id": "district-01",
  "district_name": "Район выезда №1",
  "polygon": {
    "type": "Polygon",
    "coordinates": [ ]
  },
  "stations": ["station-001", "station-002"],
  "nearest_crews": [
    {
      "crew_id": "crew-101",
      "station_id": "station-001",
      "distance_km": 1.2,
      "eta_minutes": 4
    }
  ]
}
```

### Интеграция с MAX (рассылка)

#### `POST /api/v1/notifications/max`

**Описание:** Отправить уведомление о выезде караула в чаты MAX.

**Тело запроса:**
```json
{
  "call_id": "call-9001",
  "crew_ids": ["crew-101", "crew-102"],
  "chat_ids": ["chat-psg-001", "chat-commanders"],
  "message_template": "dispatch_departure"
}
```

**Ответ:**
```json
{
  "notification_id": "notif-8001",
  "sent_at": "2026-09-12T11:16:10Z",
  "recipients": [
    {
      "chat_id": "chat-psg-001",
      "status": "sent"
    },
    {
      "chat_id": "chat-commanders",
      "status": "sent"
    }
  ]
}
```
